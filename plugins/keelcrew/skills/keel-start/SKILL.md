Use the keel-lead skill. The captain asked you to start an engineer on $ARGUMENTS now. Their request is the approval to start, whatever the difficulty. Judge the difficulty and follow the skill's Tickets steps for it (simple and moderate take the fast lane, with no scout and no critic; complex and critical run the scout if it's on, and the planning critic): write the spec and its contract into the board, run the scope check (show any cut in the Mate chat), start the engineer session the way Settings → Crew → New engineers and agents says, and reply in one line with what you started or the Start card waiting for them.
