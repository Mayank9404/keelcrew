# Starting an agent the `card` or `routine` way

Staffing step 2 of the Agents section, for agents (never an engineer or contractor), after the brief is written:

- `card` (agents only, never an engineer or contractor): `start_session` with `initiation: "own_initiative"`, `title`, `name` (the app takes at most 24 characters, lower-case letters, digits and dashes): `keel-<key>` for the engineer, `<agent id>-<key>` for other agents, with the key in lower case and any other character dropped, plus the brief id's `-2`, `-3`; over 24, shorten the key's project part and keep its number and the suffix (crew policy reads `keel-<key>` as an engineer's), the opening line as `prompt`, `background` (at least 80 characters, required by the app: the ticket key and title, the repo and its base branch, the board link, and that the brief file holds the rest), `model`, `effort`, `permission_mode: "auto"` and `use_worktree: false`. It waits as a New task card in this session and gives you its `task_id`. Then post the board card `inbox/start-<id>`: `kind: "start"`, `taskKey`, `title: "Start <KEY> <short title>"`, a one-line `body` on what the session will do, `start: {proposal: "<task_id>", model, effort}`, `sessionId` (yours), `options: ["Not now"]`, `status: "open"`, `createdAt`; never a second open start card for the same task. The captain opens this session from that card and clicks Start on your New task card. Opening it from the board also sends a `surface` request (Every wake, step 3), so your card is never lost far up the chat. On "Not now", withdraw the proposal with `dismiss_task` (on "Not withdrawn" it already started: leave the task as it is), set the card's `handledAt`, set the task back to `proposed` (the board's Start sends a `start` request when the captain wants it), and say so in chat. A proposal lives only in the Mate session that made it and lapses after a week: on start, and in daily hygiene, propose again for every open start card with a `start.proposal` whose `sessionId` isn't yours or that is over 6 days old, and update its `start.proposal`, `sessionId` and `createdAt`.
- `routine` (agents only): `create_scheduled_task` with no schedule, `taskId` `<id>`, `title: "Crew · <KEY> <short title>"`, `description: "Keelcrew <agent name> for <KEY>"` (required), and as the prompt the opening line plus "Reply only \"ready\" and end your turn. Start the work when the Mate's message saying Go arrives." Then `run_scheduled_task`: a new session opens at once in your folder, and you get its id. Apply `set_session_model` and `set_session_effort`, check both with `get_session`, then send "Go: start by using the keelcrew:<skill> skill." with `send_message`. A run uses the permission mode the task was saved in, which `create_scheduled_task`'s result reports: when it isn't `auto`, delete the task and propose the start the `card` way instead, so the session never stalls on a prompt. Keep the task until a week after the work is done (Housekeeping removes it a week after the task is done).
If a routine start is refused (by auto mode or the app), propose it the `card` way instead and say so in chat.
